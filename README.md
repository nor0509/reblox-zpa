#  reblox-zpa

> **Zespołowy projekt analityczny** | Uniwersytet Ekonomiczny w Katowicach

---

##  O projekcie

Celem projektu jest budowa oraz wdrażanie modelu uczenia maszynowego przeznaczonego do identyfikacji nisz na rynku gier wideo. 

Dane wykorzystywane w procesie analitycznym i modelowaniu pochodzą z oficjalnego interfejsu **Steam API**.
